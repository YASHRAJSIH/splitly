Splitly

Splitly is a simple Android expense-sharing application inspired by apps like Splitwise. It helps friends, roommates, and groups keep track of shared expenses and balances in one place.

Features
Create and view expense groups
Track individual balances between people
Add new expenses with amount, description, payer, and participants
Attach a bill/receipt photo using the device camera
View personal account summaries
Visualize monthly expenses with a chart
Shake the phone to simplify/summarize balances using the accelerometer
Technologies
Kotlin
Android Studio
Android 14–16
RecyclerView
Intents for Activity data exchange
Camera
Accelerometer
Local data storage
Custom View / Canvas for charts
Project Screens
The application consists of three main Activities:

Home – Groups, individual people, and current balances
Add Expense – Create an expense and attach a bill photo
My Accounts – Personal balance overview and monthly expense chart
